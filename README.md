# MFQDMA — quantile detrending moving average for multifractal time series and surfaces

Code and data accompanying

> S. Pratiher, *Quantile detrending moving average algorithm for multifractal time series and surfaces*, submitted to Physical Review E (2026).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/<YOUR-GITHUB-USERNAME>/MFQDMA-PaperI/blob/main/MFQDMA_main.ipynb)

**One notebook reproduces the whole paper.** Open `MFQDMA_main.ipynb` in Google Colab with the badge above and choose *Runtime → Run all*. The notebook clones this repository, installs the requirements, and regenerates all **17 figures** and all **11 data tables** (Tables II–XII). It then checks the figures against the manuscript versions and offers the outputs as a zip file. This takes about ten minutes.

By default the figures and tables are built from the stored numerical results in `results/`. Switch on the `RECOMPUTE` flags in Part 1 of the notebook to regenerate those results from scratch. All seeds are fixed, and recomputing reproduces the stored results exactly. Rough run times on a free Colab runtime (about 2 h in total):

| Flag | Results file | Paper items | Time |
|---|---|---|---|
| `corpus_1d` | `bench_1d.json` | Tables II, III | ~10 min |
| `advantage` | `advantage_all.json` | Table IV, Figs. 5, 6 | ~45 min |
| `analysis_2d` | `analysis_2d_all.json` | Table V, Figs. 8, 9 | ~25 min |
| `mono_2d` | `paper_2d_mono.json` | Table VI, Fig. 9 | ~5 min |
| `finance` | `finance.json` | Tables VII, VIII, Figs. 10–13 | ~15 min |
| `dem` | `dem.json` | Table XII | ~5 min |
| `eeg` | `eeg_preproc.json`, `real_eeg.json`, `eeg_main.npz`, `eeg_auc.json` | Tables IX–XI, Figs. 14–16 | ~10 min, needs the Bonn data |

Figures 1–4, 7 and 17 are computed directly in the notebook.

## Data

* **Synthetic data** are generated by `mfqdma/generators.py` with fixed seeds.
* **Financial data:** daily prices from the CRAN package *qrmdata* (M. Hofert, K. Hornik and A. J. McNeil), cloned automatically from <https://github.com/cran/qrmdata> and read by `mfqdma/rdata_reader.py`. This parser reads data only and executes nothing from the files.
* **Terrain elevation model:** `jacksboro_fault_dem.npz`, shipped with Matplotlib.
* **Bonn EEG** (R. G. Andrzejak *et al.*, Phys. Rev. E **64**, 061907, 2001): needed only to *recompute* the EEG results; the stored results are included. The data are not redistributed here. Download the five sets Z, O, N, F and S from the University of Bonn. Then set `BONN_SOURCE` in Part 1c of the notebook to the folder, to the five zip files, or to one archive with the five folders (e.g. `Dataset.rar`). `mfqdma.paths.prepare_bonn` copies them to `data/bonn/`.

## Running locally

```bash
pip install -r requirements.txt
jupyter notebook MFQDMA_main.ipynb
```

The functions can also be used directly, e.g.

```python
from mfqdma.methods import mfqdma
r = mfqdma(x, q_list, scales, theta=0.0, tau=0.25)   # tau is the quantile level lambda
r['hq'], r['tau_q'], r['alpha'], r['f_alpha']
```
